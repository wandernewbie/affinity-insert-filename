
# Insert Filename for Affinity

Affinity（by Canva）で、選択したテキストオブジェクトに、現在開いているドキュメントのファイル名を挿入するスクリプトです。

## できること

- 選択したテキストオブジェクトの文字列を、ドキュメントのファイル名に置き換えます。
- ファイル名を手入力する手間を減らせます。

> **注意:** 選択したテキストオブジェクトに既に文字が入っている場合、その文字列は置き換えられます。実行前に対象を確認してください。

## 動作環境

- Affinity（by Canva）3.3.3（作成時の使用バージョン）
- その他のバージョンでの動作は未確認です。

## インストール方法

1. このリポジトリの [Releases](https://github.com/wandernewbie/affinity-insert-filename/releases) から `.afscript` ファイルをダウンロードします。
2. Affinityの **スクリプト** パネルを開きます。
3. スクリプトのメニューから **スクリプトをインポート** を選び、ダウンロードした `.afscript` ファイルを指定します。
4. スクリプト一覧に追加されたら、インストール完了です。



## 使い方

1. Affinityで対象のドキュメントを開きます。
2. ファイル名を入れたい **テキストオブジェクトを1つ選択** します。
3. **スクリプト** パネルから「Insert Filename」を実行します。
4. 選択したテキストがドキュメントのファイル名に置き換わります。

## ソースコード

編集用のJavaScriptは [`affinity_insert_filename.js`](./affinity_insert_filename.js) です。

`.js` は編集・学習向け、`.afscript` はAffinityへのインストール向けの配布ファイルです。

## 注意事項

- 実行前に作業中のドキュメントを保存しておくことをおすすめします。
- 未保存ドキュメントや複数選択時などの動作は、利用するスクリプトの実装をご確認ください。
- Affinity / Canvaの公式スクリプトではありません。
