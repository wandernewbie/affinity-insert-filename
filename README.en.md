# Insert Filename for Affinity

[日本語](./README.md)

📦 [Download latest release](https://github.com/wandernewbie/affinity-insert-filename/releases/latest)

This script for Affinity by Canva replaces the contents of a selected text object with the name of the open document.

## Compatibility

The script was developed with Affinity 3.3.3. Other versions have yet to be tested.

## Installation

1. Download the `.afscript` file from [Releases](https://github.com/wandernewbie/affinity-insert-filename/releases).
2. Open the **Scripts** panel in Affinity.
3. In the panel menu, choose **Import Script** and select the downloaded file.
4. **Insert Filename** should now appear in the script list.

## Usage

1. Open your document in Affinity.
2. Select one text object. Any existing text in that object will be replaced.
3. Run **Insert Filename** from the **Scripts** panel.

## Source code

The editable JavaScript source is [`affinity_insert_filename.js`](./affinity_insert_filename.js). The `.afscript` release file is the package you import into Affinity.
